# 故障排查

[English](TROUBLESHOOTING.md)

## 阅读器提示配置数据目录

打开“设置 → Academic RSS Reader”，输入当前 Vault 内的相对目录，然后：

- 目录内已有有效 `rss-reader.sqlite3` 时选择“载入数据库”。
- 目录内没有数据库时才选择“创建新数据库”。

插件拒绝绝对路径和包含 `..` 的越界路径，也不会在启动阶段自动创建数据库。

## 数据库无法载入

校验失败时，插件会保留原文件不变。

1. 确认所选目录位于当前 Vault 内。
2. 确认目录中存在 `rss-reader.sqlite3`。
3. 排查期间不要覆盖或删除原数据库。
4. 如果存在有效备份，可在设置中使用“恢复最近备份”；恢复前插件会再次创建保护备份。

备份保存在所选数据目录的 `backups/` 子目录。

如果保存或恢复过程被中断，插件仅在正式库缺失或校验失败时，依次检查
`rss-reader.sqlite3.tmp`、`rss-reader.sqlite3.previous`、`rss-reader.sqlite3.incoming` 和
`rss-reader.sqlite3.rollback`。自动恢复前不要重命名或删除这些文件。若所有快照均无效，插件会保留它们并要求从 `backups/` 恢复。

## 将数据移动到其他目录

数据库已运行时，使用“迁移当前库”复制到空目标目录；迁移不会覆盖已有目标数据库。

目标目录已有有效数据库时使用“载入目标库”。不要使用外部文件工具移动正在打开的数据库。

## 订阅更新失败

- 1.2.0 会显示订阅健康状态和连续失败次数。自动更新连续失败后会退避；单个订阅的手动更新可以立即重试。
- HTTP 304 表示缓存验证成功，并不是空订阅。
- 调度器等待 20 秒后按超时处理。Obsidian `requestUrl()` 无法中断已经发出的请求，但取消或超时后的迟到响应会被忽略且不会写入数据库。
- 确认订阅地址是有效的 HTTP 或 HTTPS URL。
- 在浏览器中打开地址，检查来源是否可访问。
- 单个订阅失败不会阻止成功订阅保存结果。
- 断网时仍可阅读已有本地文献。

## 标题翻译失败

标题翻译使用 Google 非正式网页接口，可能被限流、受地区影响或因上游变化失效。每次请求最多等待 15 秒；网络、限流和服务器错误会按递增间隔最多自动尝试三次。达到上限后停止自动请求，并在阅读器保留“重试翻译”入口。失败不会覆盖原标题，也不会阻塞阅读、订阅、推荐或兴趣分析。

网络恢复后可点击“重试翻译”，也可以关闭标题翻译继续使用原标题。目标语言可在设置中选择；原始语言会自动识别。

## LLM 连接测试失败

检查以下三项：

- OpenAI 兼容的 HTTPS API 地址。
- 或者使用 `localhost`、`127.0.0.1`、`::1` 的本机 HTTP 地址；其他 HTTP 地址会被拒绝。
- 保存 API Key 的 SecretStorage 条目。
- 服务支持的有效模型名称。

连接测试要求数据库已经载入。API Key 保存在 Obsidian SecretStorage，不会进入 SQLite 数据库或备份。

## 界面语言不正确

插件在启动时读取应用语言：

- 中文语言环境显示简体中文。
- 英文及其他语言环境回退英文。

修改应用语言后，请重新加载应用，或禁用再启用插件。标题翻译的目标语言与界面语言相互独立。

## 运行时提示不支持 node:sqlite

v1.4.0 不再包含 `sql.js` fallback。请更新到提供 Node.js 22.16+、`node:sqlite`
`DatabaseSync` 和 SQLite Backup API 的 Obsidian 桌面版；更新后重新打开阅读器。数据库不会
在不满足要求的运行时被载入。

## 安装与升级

推荐打开“设置 → 第三方插件 → 浏览”，搜索 **Academic RSS Reader**，然后安装并启用。

手动安装仅作为备用方案。升级时只替换 `main.js`、`manifest.json`、`styles.css`，保留 `data.json` 和用户选择的 Vault 数据目录。不要把 SQLite 数据库放入插件目录。
