# RSS Reader v1.0.1

## 更新行为

- 每次启动 Obsidian 后，首次打开 RSS Reader 时在后台静默更新启用的订阅。
- 插件启动阶段不弹出更新通知；手动更新仍显示进度和结果。

## 数据目录初始化

插件启用时不在插件目录创建数据库。首次打开 RSS 面板会提示进入设置，选择当前 Vault 内的数据目录后，可以创建新的 `rss-reader.sqlite3` 或载入目录中已有的有效数据库。

插件只在数据库就绪后启动订阅、翻译、推荐和 LLM 服务。损坏或不兼容的数据库不会被覆盖，也不会触发恢复数据库回退。

数据目录采用：

```text
<用户选择的数据目录>/
├── rss-reader.sqlite3
└── backups/
```

- “迁移当前库”只允许写入没有同名数据库的目标目录。
- “载入目标库”要求目标数据库通过 SQLite 完整性与核心表校验。
- 切换和恢复前先在当前 `backups/` 中创建保护性备份。
- 任一切换步骤失败时继续使用原数据库，且不保存目标目录设置。
- 不提供定时备份；用户可以从设置页手动创建备份。
- 不提供旧数据库导入功能。

## 升级说明

更新插件只覆盖 `main.js`、`manifest.json` 和 `styles.css`，不要覆盖 `data.json`。插件不扫描或迁移旧插件目录中的 `rss-reader.sqlite3`。
