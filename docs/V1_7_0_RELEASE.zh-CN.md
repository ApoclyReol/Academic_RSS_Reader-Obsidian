# Academic RSS Reader v1.7.0

[English](V1_7_0_RELEASE.md) | 简体中文

本版本改进阅读器及相关页面的搜索和长列表导航体验。

## 主要更新

- 阅读器支持在当前篮子中按关键词模糊搜索，覆盖标题、作者、期刊、摘要、DOI、订阅元数据，以及已成功缓存的标题或摘要译文。
- 订阅管理和兴趣分析也新增搜索；输入采用延迟刷新，中文输入法的预输入过程不会被打断。
- 长列表滚动时，篮子导航、搜索和排序控件保持可见；“返回顶部”持续显示在右下角，到达列表底部时自然回到列表末端的位置。
- 简化阅读器操作区：翻译按钮置于首位，相关操作使用竖线分组；个性化推荐改为按钮打开紧凑弹窗，信息和带文字的操作按钮更清晰。

本版本不修改 SQLite schema、设置或已有数据。

> [!IMPORTANT]
> 需要 Obsidian 1.13.0 或更高版本的桌面端。GitHub Release 仅安装
> `main.js`、`manifest.json` 和 `styles.css`。
