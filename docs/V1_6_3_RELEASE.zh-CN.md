# Academic RSS Reader v1.6.3

[English](V1_6_3_RELEASE.md) | 简体中文

本次补丁为长列表阅读增加了一个小型导航优化。

## 主要更新

- 每个文献篮子的全部文献加载完成后，列表底部会显示“返回顶部”按钮。
- 点击后返回当前阅读器滚动容器顶部，按钮支持键盘和触控，并提供中英文文案。

本补丁不修改 SQLite schema、设置或已有数据。

> [!IMPORTANT]
> 需要 Obsidian 1.13.0 或更高版本的桌面端。GitHub Release 仅安装
> `main.js`、`manifest.json` 和 `styles.css`。
