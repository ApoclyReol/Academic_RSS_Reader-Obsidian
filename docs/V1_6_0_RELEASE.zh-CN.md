# Academic RSS Reader v1.6.0

[English](V1_6_0_RELEASE.md) | 简体中文

本次功能更新允许用户配置文献卡片显示的研究元数据，同时保持稳定、低干扰的阅读布局。

## 主要更新

1. 设置新增“文献卡片”分组，可控制期刊、作者、发表日期、DOI、订阅源文本摘要和摘要图；
   标题、推荐依据和操作始终保留。
2. 所有卡片根据全局启用的行槽使用统一高度；单篇字段缺失和图片加载状态不会改变卡片高度。
3. 发表日期按界面语言格式化并在必要时回退到年份；仅含标签元数据的订阅摘要不会被误当成
   文本摘要，同时数据库原文和推荐特征保持不变。
4. 全部字段启用时，期刊、日期和 DOI 保持在同一行左对齐连续排列，作者和摘要共用固定标签列，
   同一配置下卡片高度仍然统一。
5. 关闭摘要图后不会创建卡片图片元素或发起对应远程请求；启用时继续支持懒加载、失败回退
   和键盘可访问的放大预览。

## 修复与优化

- 点击“感兴趣”“归档”“隐藏”或“恢复”等状态操作后，会保留当前阅读位置，不再跳回列表顶部。
- 全部可选字段启用时，卡片间距更加紧凑；作者和摘要正文从同一固定标签列起始。超长内容会在对应行内裁切，
  悬停仍可查看完整文本。

旧设置会自动补齐默认值，并保持 v1.5.0 的卡片外观。本版本不修改数据库 schema。

> [!IMPORTANT]
> 需要 Obsidian 1.13.0 或更高版本的桌面端。若内置运行环境不兼容，插件会提示升级
> Obsidian。

只安装 GitHub Release 中的 `main.js`、`manifest.json` 和 `styles.css`。
