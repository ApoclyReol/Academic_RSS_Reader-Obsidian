# Academic RSS Reader v1.4.1

[English](V1_4_1_RELEASE.md) | 简体中文

本次补丁更新：

- 支持 Nature 期刊使用的 RSS 1.0/RDF 订阅；
- 支持解析 RSS 1.0 的 `dc:date` 发布日期；
- 消除 Obsidian 样式与干净构建兼容性警告。

> [!IMPORTANT]
> 仅支持 Obsidian 1.13.0 或更高版本的桌面端，内置运行时还需提供 Node.js 22.16+ 和
> `node:sqlite`。

只安装 GitHub Release 中的 `main.js`、`manifest.json` 和 `styles.css`。
